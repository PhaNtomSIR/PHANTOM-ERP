🌐 Enterprise Resource Planning (ERP) Deployment Topologies

ERP systems operate across distinct deployment models based on compliance, operational latency, and scalability requirements.

☁️ Cloud-Based (SaaS)

Hosted on multi-tenant or dedicated managed hyperscaler cloud infrastructure (AWS, Azure, GCP).

  • Automated zero-downtime upgrades
  • Dynamic horizontal auto-scaling
  • Low upfront CapEx / OPEX subscription
  • Global high-availability multi-region replicas

🏢 On-Premises

Installed directly on customer-owned bare metal or private virtualization cluster in local corporate datacenter.

  • Total sovereign control over sensitive financial data
  • Strict regulatory compliance (defense, banking, healthcare)
  • Zero external dependency on internet backbones
  • Direct integration with local SCADA / PLC devices

⚡ Hybrid Architecture

Synchronizes local edge nodes (plant floor manufacturing & warehouse scanners) with cloud central ERP.

  • Offline local factory operational continuity
  • Asynchronous central database replication
  • Best of both worlds: Cloud analytics + Local speed
  • Active bidirectional event streams

🗄️ Central Database & System Topology Information

Current Server Runtime: Java 21 (Eclipse Temurin LTS 64-Bit) on Spring Boot 3.3.4
Database Type: Relational Unified Store (In-Memory H2 for development; switchable to PostgreSQL / Oracle / MS SQL for production)
Web & DB Port: Port 8080 (Web UI & REST APIs) / /h2-console (Direct Database Inspection)
Single Source of Truth: Connected cross-table foreign key constraints linking Finance, HR, Procurement, Sales, and Manufacturing.
Real-Time Automation: Transactional workflows auto-dispatch inventory, generate AP/AR invoices, and post balanced GL journal entries upon trigger.
